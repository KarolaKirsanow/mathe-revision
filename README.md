

# Revisionsplan Mathe 8 → 9

Ein interaktiver Ein-Seiten-Revisionsplan für
Mathematik Klasse 8 → 9 (Lambacher Schweizer,
Ausgabe Baden-Württemberg). Gegliedert nach den
Kapiteln der Klassenarbeitstrainer, mit
Lehrerschmidt-Videos und Serlo-Übungen pro
Kapitel und einem Fortschrittsbalken.

Alles steckt in einer einzigen `index.html` –
kein Build, keine Abhängigkeiten.


## Anpassen

Die Videos und Links stehen direkt als
`<a>`-Elemente im HTML. Zum Ändern einfach die
Datei in einem Editor öffnen und die URLs oder
Kapiteltexte ersetzen.

## Hinweis zum Fortschritt

Der Fortschritt wird lokal im Browser
gespeichert (localStorage). Beim nächsten
Besuch auf demselben Gerät und im selben
Browser sind die abgehakten Kapitel noch da.
Über den Button "Fortschritt zurücksetzen"
lässt sich alles wieder leeren. Ein anderes
Gerät oder Browser startet mit eigenem,
leerem Stand.
